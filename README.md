پروژه‌های پایتون 🐍

در این مخزن دو پروژه با زبان برنامه‌نویسی پایتون قرار داده شده است.

📁 پروژه اول: ساختارهای شرطی و حلقه‌ها

فایل: "python_if_for_while.py"

در این برنامه چند نمونه از دستورات شرطی و حلقه‌های تکرار پایتون نوشته شده است.

موارد استفاده‌شده:

- دستورهای "if"، "elif" و "else"
- تشخیص مثبت، منفی یا صفر بودن عدد
- حلقه "for"
- پیمایش اعضای لیست
- حلقه "while"
- شمارش اعداد
- بررسی رمز عبور

- توان و جذر

- محاسبه میانگین و درصد
- محاسبه قدر مطلق
- تشخیص زوج و فرد
- تشخیص عدد اول
